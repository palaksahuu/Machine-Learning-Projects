# Boston Housing Price Analysis

This project performs exploratory data analysis and basic preprocessing on the Boston Housing dataset using Python. The objective of the project is to understand the dataset, explore feature distributions, and prepare the data for machine learning models that can predict housing prices.

The analysis includes loading the dataset, inspecting its structure, analyzing statistics, visualizing feature distributions, and splitting the dataset into training and testing sets.

---

## Dataset Overview

The dataset contains information about housing in Boston suburbs and various factors that may influence housing prices.

Each row represents a housing record, and each column represents a specific feature related to the property or neighborhood.

### Features in the Dataset

- CRIM: Per capita crime rate by town  
- ZN: Proportion of residential land zoned for large lots  
- INDUS: Proportion of non-retail business acres per town  
- CHAS: Charles River dummy variable (1 if tract bounds river, 0 otherwise)  
- NOX: Nitric oxide concentration  
- RM: Average number of rooms per dwelling  
- AGE: Proportion of owner-occupied units built before 1940  
- DIS: Weighted distances to employment centers  
- RAD: Index of accessibility to radial highways  
- TAX: Property tax rate per 10,000 dollars  
- PTRATIO: Pupil-teacher ratio by town  
- B: Proportion related to racial demographics  
- LSTAT: Percentage of lower status population  
- MEDV: Median value of owner-occupied homes (target variable)
