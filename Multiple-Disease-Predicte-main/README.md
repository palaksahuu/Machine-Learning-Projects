# Multiple Disease Prediction System

This project is a machine learning web application built using Python and Streamlit that predicts the likelihood of multiple diseases based on user input. The system currently supports prediction for three diseases:

- Diabetes
- Heart Disease
- Parkinson's Disease

The application allows users to enter medical parameters through a web interface and receive predictions generated by trained machine learning models.

---

## Project Overview

The goal of this project is to demonstrate how machine learning models can be integrated into a simple web application for healthcare-related predictions.

The system loads pre-trained machine learning models and uses them to make predictions based on the data entered by the user.

The application is built with Streamlit to provide a simple and interactive user interface.

---

## Features

- Predicts Diabetes risk based on medical input values
- Predicts Heart Disease risk using clinical parameters
- Predicts Parkinson's Disease based on voice measurement features
- User-friendly interface built with Streamlit
- Sidebar navigation for selecting different prediction modules
- Real-time prediction after entering input values

---

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Joblib / Pickle (for loading trained models)
- Streamlit Option Menu
